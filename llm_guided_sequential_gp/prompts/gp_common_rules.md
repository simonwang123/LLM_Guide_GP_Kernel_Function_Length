# LLM 引导序贯 GP：长度尺度先验共用规则

## 当前任务

根据已提供的工程背景和有限元观测，为三个变形响应分别判断八个几何变量的 GP 长度尺度先验中心。输入按固定物理边界归一化到 [0, 1]；每个响应使用独立的八维 ARD Matérn 5/2 GP。

冷启动阶段对 3 × 8 个响应—变量关系给出初始判断；序贯阶段根据新揭晓的样本和已封存的事前预测，提出下一次拟合可检验的先验调整。你的判断是模型假设；程序拟合并比较候选后决定是否采纳。具体输入字段、候选数量和 JSON 格式由阶段提示词规定。

## 先验类别的含义

对响应 r、变量 j，令 θ_rj = log(ℓ_rj)。拟合器使用软先验 θ_rj ~ Normal(μ0 + δ_rj, τ²)，其中 μ0 = log(c) + 0.5 log(8)。基准系数 c 和先验宽度 τ 由程序固定。你选择的是 δ_rj 的类别：

| 类别 | δ_rj | 长度尺度几何中心相对基准 | 适用假设 |
| --- | ---: | ---: | --- |
| short | −log(2) | 1/2 | 有理由认为该方向变化较快 |
| base | 0 | 1 | 证据不足，沿用共同基准 |
| long | +log(2) | 2 | 有理由认为该方向变化较平缓 |

类别改变先验中心，最终长度尺度仍由训练数据拟合。长度尺度描述变化距离，不决定响应变化的正负号；较长尺度也不等于变量没有作用。

## 如何使用证据

- 冷启动阶段依据前 20 个样本的统计摘要和工程知识。序贯阶段依据更新到本步的统计摘要、事前预测误差、三近邻泰勒一阶贡献和现有模型状态。输入不提供逐样本坐标或响应历史；不得编造对具体历史样本的比较。分别判断三个约束响应。
- prior_sign 和 prior_tier 描述已有工程知识的方向与强度，不直接决定长度尺度。偏相关、单变量二次增益、模型预测增量贡献和拟合长度尺度可以支持待检验假设，不能据此断言单变量因果作用。Top-3 是预测增量主导的偏差排查候选，并非真实预测残差的归因。
- 可以依据工程知识和已揭晓数据，建议某个变量采用更短或更长的长度尺度先验中心。如果某一次当前高斯过程模型对下一个样本点的预测误差大，但是如果你无法判断是哪个变量造成的，那么就不能只凭这次误差就修改某个变量。所以如果你在提出建议时，请写明建议所依据的观测和理由；依据不足时，冷启动选 base，序贯保持当前类别。

## 数据时序

冷启动只使用前 20 个样本。序贯第 t+1 步须先由 M_t 对 x_(t+1) 封存预测，再揭晓该点真值；揭晓后的信息只用于下一次拟合的建议。未来样本真值和独立测试集不得用于建议或采纳。只按阶段提示词输出一个合法 JSON 对象。
