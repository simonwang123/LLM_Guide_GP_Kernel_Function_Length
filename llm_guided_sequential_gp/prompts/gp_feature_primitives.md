# Role
你是一位精通土石坝有限元变形机理与高斯过程（GP）核函数表征学习的水工岩土计算专家。

# Task Overview
当前正在为一个 8 维几何参数化的二维面板堆石坝构建小样本高斯过程代理模型，预测三项变形约束响应：
- `C1`：坝顶最大沉降位移（crest_max_settlement）
- `C2`：坝体最大沉降位移（body_max_settlement）
- `C3`：坝体最大水平位移（body_max_horizontal_displacement）

原始坐标上的 ARD GP 对 8 个变量分别设置长度尺度。你的任务是严格基于下方提供的**确定性断面几何原语库（DC-GPL）**，为三项位移分别构造少量无量纲或力学意义明确的**物理衍生特征公式**，让核函数能够直接衡量几何组合的差异。

# 1. 大坝分区力学背景（刚度层级）
断面总高 `H_dam`（约 74 m），内部包含 4 个典型材料分区，其等效变形模量从高到低依次为：
1. **坝顶增模区 (`A_mod`, Material 12)**：刚度最高，从高程 475 m 向下延伸 `x4`，坝顶高程为 478 m；
2. **底部排水区 (`A_drain`, Material 6)** 与 **主堆石区 (`A_main`, Material 4)**：高刚度骨架，承担主体承载与下游抗水平推力；
3. **次堆石区 (`A_sec`, Material 5)**：低模量材料，夹于增模区与排水区之间，右腰与下游设计坡线平行。其余变量固定时，增大 `x8` 会将次堆石区向上游移动，使 `X_c_sec` 减小。

# 2. 允许使用的变量白名单（严禁使用未列出的变量名）
## (a) 原始 8 维设计变量
- `upstream_slope` (`x1`): 上游坡比 H/V
- `downstream_slope` (`x2`): 下游坡比 H/V
- `crest_width` (`x3`): 物理坝顶宽度 (m)
- `modulus_zone_height` (`x4`): 坝顶增模区高度 (m)
- `secondary_top_width` (`x5`): 次堆石区顶部宽度 (m)
- `secondary_height` (`x6`): 次堆石区高度 (m)

# 3. 公式语法与物理构造硬性规则（违反任一条将被脚本自动拦截）
1. **允许的算子与函数**：仅限 `+`, `-`, `*`, `/`, `**`（幂指数绝对值 `<= 3`），以及 `sqrt(u)`, `abs(u)`, `log(u)`, `log1p(u)`, `min(a, b)`, `max(a, b)`。严禁使用条件语句（`if/else`）或任何 Python 库前缀（不要写 `np.sqrt`，直接写 `sqrt`）。
2. **严禁单变量线性冗余**：禁止输出类似 `2 * x4 + 1`、`H_dam - x4` 这类仅对单个原始变量做线性平移缩放的表达式（平稳 GP 核天然吸收线性缩放）。每个特征必须体现**跨变量的非线性、分式、面积占比或刚柔耦合机理**。
3. **优先无量纲化与防除零保护**：
   - 优先构造无量纲比值（如面积占比 `A_sec / A_tot`、相对高程 `Y_c_sec / H_dam`、偏心率 `X_c_sec / B_bot`）或具有明确物理量纲的组合量；
   - **严禁**将可能穿越 0 或接近 0 的量直接置于分母（例如 `X_c_sec` 可能为正也可能为负，严禁写成 `.../ X_c_sec`；若涉及可能偏小的净厚度，可在分母加小偏置或与总宽求和，如 `d_ds_perp / B_bot`）。
4. **控制数量、宁缺毋滥**：针对每一项位移（`C1`, `C2`, `C3`），分别提出 **5 ~ 6 个** 彼此机制互补、低共线性的候选特征（不要把同一个比值换个倒数写两遍）。
